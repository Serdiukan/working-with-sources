# Working with Sources

Methods for turning historical sources into research databases: coding manuals, data models, code lists, quality control and test scenarios.

This repository publishes **methodology only**. It contains no transcriptions of sources and no coded data. Datasets are released separately, with their own documentation and DOI.

## Projects

| Project | Source | Status |
|---|---|---|
| [General Description of the Hetmanate, 1765–1769](general-description-1765-1769/) | The General (Rumiantsev) Description: a household-level inventory of the Hetmanate. First settlement: Poltava, town and suburb | Method v1.0. Poltava fully coded. Dataset release in preparation |

Each project lives in its own folder with its own README, documentation, schema and tests. More source projects will be added in the same way.

## What a project folder contains

- **README** — the source, the status of the work and what the folder holds.
- **docs/** — the coding manual, data model, reading conventions, quality assurance and workflow.
- **schema/** — machine-readable lists of tables, fields and codes.
- **tests/** — test scenarios: short synthetic situations with the expected coding decision. They are used to check a new coder, human or AI, before real work begins.
